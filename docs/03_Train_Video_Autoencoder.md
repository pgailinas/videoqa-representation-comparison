## Purpose

This notebook trains a self-supervised video autoencoder using the standardized training data generated by Notebook 02. The primary objective is to learn compact latent video representations that can be used for downstream VideoQA tasks and compared with CLIP-based video representations.

During training, the autoencoder learns these representations through a self-supervised reconstruction objective. Reconstruction quality is monitored as a training metric rather than as the primary research outcome.

The resulting autoencoder model establishes the project's baseline representation-learning workflow and provides a foundation for evaluating future enhancements to model architecture, latent-space design, training strategies, and reconstruction quality.

The trained autoencoder model and learned latent video representations produced by this notebook serve as the primary inputs for downstream representation-based VideoQA experiments.

### Autoencoder Training Strategy

The current implementation uses a convolutional autoencoder trained in a self-supervised manner. Training data is generated directly from the standardized video segments prepared by Notebook 02.

Representative frames are sampled from each evidence segment and resized to a fixed input resolution. During training, the encoder compresses each frame into a latent representation, and the decoder attempts to reconstruct the original frame from that representation.

Although reconstruction is used as the self-supervised training objective, the primary goal of this notebook is to learn compact latent video representations that preserve information useful for downstream VideoQA tasks.

### Autoencoder Configuration Parameters

The baseline implementation uses configurable project settings for model architecture and training behavior.

| Parameter               | Description                                                           |
| ----------------------- | --------------------------------------------------------------------- |
| Frame Size              | Input image resolution used during training and reconstruction.       |
| Frames per Segment      | Number of frames sampled from each video segment.                  |
| Batch Size              | Number of training samples processed in each optimization step.       |
| Epochs                  | Number of complete passes through the training dataset.               |
| Latent Dimension        | Size of the compressed latent representation produced by the encoder. |
| Learning Rate           | Optimization step size used during model training.                    |
| Development Subset Size | Number of videos selected for development-stage experimentation.      |

Future experiments may evaluate alternative values for these parameters and compare their effects on reconstruction quality and downstream VideoQA performance.

### Training Reconstruction Metrics

Reconstruction quality is evaluated using several standard image-reconstruction metrics.

| Metric | Description                                                    |
| ------ | -------------------------------------------------------------- |
| MSE    | Mean Squared Error between original and reconstructed frames.  |
| MAE    | Mean Absolute Error between original and reconstructed frames. |
| PSNR   | Peak Signal-to-Noise Ratio measuring reconstruction fidelity.  |

These metrics monitor training progress and help verify that the learned latent representations capture meaningful visual information during self-supervised learning.

### Development Experiment Configuration

The notebook operates on a development subset of the NExT-QA dataset to support rapid experimentation.

The baseline development configuration currently uses:

* Development subset of selected videos
* Training metadata generated by Notebook 02
* Fixed frame sampling per evidence segment
* Convolutional autoencoder architecture
* Self-supervised representation learning using a reconstruction objective
* GPU-accelerated training when available

This approach allows rapid evaluation of autoencoder design choices before executing full-dataset experiments.

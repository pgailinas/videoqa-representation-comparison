## Purpose

This notebook trains a self-supervised autoencoder using video evidence segments generated by the NExT-QA VideoQA representation-learning project. The notebook learns compressed latent representations of video content and evaluates the ability of those representations to reconstruct the original evidence segments.

Using evidence metadata generated by Notebook 02, representative frames are sampled from evidence segments and used to train a convolutional autoencoder. The encoder learns compact latent representations while the decoder reconstructs the original visual content from those latent representations.

The resulting autoencoder model establishes the project's baseline representation-learning workflow and provides a foundation for evaluating future enhancements to model architecture, latent-space design, training strategies, and reconstruction quality.

The trained autoencoder, latent representations, reconstructed evidence samples, and reconstruction metrics produced by this notebook serve as inputs for downstream VideoQA experimentation and comparison against baseline VideoQA performance.

### Autoencoder Training Strategy

The current implementation uses a convolutional autoencoder trained in a self-supervised manner. Training data is generated directly from evidence segments without using NExT-QA question-answer labels.

Representative frames are sampled from each evidence segment and resized to a fixed input resolution. During training, the encoder compresses each frame into a latent representation, and the decoder attempts to reconstruct the original frame from that representation.

The objective is to learn compact visual representations that preserve information useful for downstream VideoQA tasks while reducing the dimensionality of the original video content.

### Autoencoder Configuration Parameters

The baseline implementation uses configurable project settings for model architecture and training behavior.

| Parameter               | Description                                                           |
| ----------------------- | --------------------------------------------------------------------- |
| Frame Size              | Input image resolution used during training and reconstruction.       |
| Frames per Segment      | Number of frames sampled from each evidence segment.                  |
| Batch Size              | Number of training samples processed in each optimization step.       |
| Epochs                  | Number of complete passes through the training dataset.               |
| Latent Dimension        | Size of the compressed latent representation produced by the encoder. |
| Learning Rate           | Optimization step size used during model training.                    |
| Development Subset Size | Number of videos selected for development-stage experimentation.      |

Future experiments may evaluate alternative values for these parameters and compare their effects on reconstruction quality and downstream VideoQA performance.

### Reconstruction Metrics

Reconstruction quality is evaluated using several standard image-reconstruction metrics.

| Metric | Description                                                    |
| ------ | -------------------------------------------------------------- |
| MSE    | Mean Squared Error between original and reconstructed frames.  |
| MAE    | Mean Absolute Error between original and reconstructed frames. |
| PSNR   | Peak Signal-to-Noise Ratio measuring reconstruction fidelity.  |

These metrics provide quantitative measures of reconstruction quality and enable comparison between alternative autoencoder architectures and training configurations.

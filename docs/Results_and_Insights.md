## Runtime Environment Observations

Experiments were conducted using Google Colab.

During testing, Qwen2-VL-7B executed reliably on NVIDIA L4 GPUs. NVIDIA T4 runtimes frequently experienced memory limitations during inference, resulting in CUDA out-of-memory failures for some evaluation samples.

For reproducible execution of the baseline workflow, L4 GPU runtimes are recommended.
